# Jollibee Smart Serve
A Smart Ordering and Billing Management System

## Purpose
Speeds up order processing, reduces order errors, and ensures accurate billing for dine-in and takeout orders.

## Key Features
- Digital menu management
- Order management (dine-in and takeout)
- Automatic billing and change computation
- Payment recording (cash, card, e-wallet)
- Order status monitoring (Pending, Preparing, Ready, Completed)
- Transaction reports
- QR code access
